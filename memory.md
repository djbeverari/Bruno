#### Dia 1 — Completo (12 horas) ✅

**Hora 1: MSEP — 7 Conceitos-Chave**

1. Competência = mobilizar CHA + Valores para desempenho em trabalho real
   - Não é só saber, é saber fazer em contexto
   - Se observa pelo desempenho
   
2. Capacidades (base para competências):
   - Técnicas: saber fazer + contextualização (ex: "operar torno considerando especificações")
   - Socioemocionais: postura, habilidades emocionais
   - Básicas: leitura, escrita, raciocínio lógico
   - ⚠️ Devem ser desempenhos específicos + observáveis + contextualizados

3. Perfil Profissional = norte de todo planejamento

4. Situação de Aprendizagem = Contexto + Desafio + Dados
   - Docente provoca com desafio real, não "dá aula sobre"

5. Avaliação (3 funções complementares):
   - Diagnóstica: no início, identifica prévios, não gera nota
   - Formativa: durante processo, contínua, com intervenção imediata
   - Somativa: ao final, verifica desempenho final

6. Mediação Pedagógica:
   - Intencionalidade: ação deliberada com propósito pedagógico
   - Transcendência: questionamentos que generalizam aprendizado

7. Plano de Ensino = docente elabora, coordenação valida
   - Elo direto com o cargo: Orientador orienta e valida

**Hora 2: Avaliação por Competências — 7 Componentes**

1. Princípio: Processo contínuo diagnóstico e formativo (não evento pontual)

2. Três Funções (complementares):
   - Diagnóstica: antes/início
   - Formativa: durante processo (onde acontece recuperação contínua)
   - Somativa: ao final

3. Quatro Níveis de Desempenho:
   - Autônomo ✅ (esperado para certificação)
   - Parcialmente Autônomo
   - Apoiado
   - Não Satisfatório

4. Critérios de Avaliação:
   - Observáveis: visíveis e registráveis
   - Suficientes: cobrem essencial
   - Progressivos: simples → complexo

5. Recuperação da Aprendizagem:
   - Contínua: durante aula, docente intervém imediatamente ⚠️ TIPO 1
   - Paralela: fora horário regular ⚠️ TIPO 2
   - Orientador orienta quando/como acionar cada uma

6. Conselho de Classe: espaço colegiado para decisões sobre desempenho

7. Frequência: mínimo 75% para certificação

**Hora 3: Plano de Curso vs Plano de Ensino — 8 Diferenciais**

| Aspecto | Plano de Curso | Plano de Ensino |
|---------|---|---|
| Tipo | Institucional | Pedagógico |
| Escopo | Macro (todo curso) | Micro (dia a dia) |
| Elabora | CES ou escola | Docente |
| Aprova | Coordenação + GED | Coordenação |
| Conteúdo | Objetivo, perfil, organização curricular, avaliação | Situação de aprendizagem, capacidades, critérios, estratégias |

**Fluxo FIC para Atendimento Empresa** (MUITO IMPORTANTE para prova):
1. Identificar demanda com profundidade
2. Consultar cursos normalizados (SGSET)
3. Consultar Fichas de Produto (própria escola)
4. Consultar Fichas de Produto (outras escolas)
5. Criar Ficha de Produto inédita (só se nenhuma atender)
⚠️ Se virar recorrente → Plano de Curso

**Ficha de Produto**: atendimento pontual/específico, título inédito, não permite aproveitamento

**Papel do Orientador**: orienta elaboração plano ensino, valida alinhamento com plano curso, acompanha situações desafiadoras, intervém em desvios pedagógicos

#### Coaching para Melhoria

**Erro 1: Papel do Orientador x Papel do Docente**

Pergunta SEMPRE: **"Quem executa? Quem orienta?"**

- Docente executa (planeja, aplica, avalia, recupera)
- Orientador orienta, acompanha, monitora (não executa)

Frase modelo: "Cabe ao Orientador orienta o docente sobre... acompanhar se... e monitorar indicadores que evidenciam..."

**Erro 2: Conclusão sem Processo**

Pergunta SEMPRE: **"Qual é o processo que justifica essa conclusão?"**

Em Manual FIC, sempre o fluxo de 5 etapas. GRAVE:

```
1º Identificar demanda
2º Consultar normalizados (SGSET)
3º Consultar Fichas próprias
4º Consultar Fichas outras
5º Criar Ficha inédita
⚠️ Se recorrente → Plano Curso
```

**Estrutura Padrão para TODA Resposta Dissertativa**:
1. Diagnóstico (o que está errado + por quê)
2. Fundamentação (qual princípio embasa)
3. Caminho correto (processo completo, passo a passo)
4. Papel do Orientador (como atua especificamente)
