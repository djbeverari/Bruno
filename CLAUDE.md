# Contexto Persistente - Bruno

## Carregamento Automático de Memória

Este projeto contém um arquivo `memory.md` com contexto persistente de Bruno.

**Arquivo Principal:** `memory.md`

Contém:
- Perfil profissional e pessoal
- Histórico de chats estruturado com insights
- Preferências de trabalho
- Conhecimentos e expertise
- Aprendizados e feedback

## Como Funciona

Quando você abrir este projeto no Claude Code, eu tenho acesso a este arquivo e posso:
- Consultar histórico de conversas anteriores
- Manter contexto consistente sobre quem é Bruno
- Aplicar feedback e lições aprendidas
- Continuar trabalhos em andamento

## Estrutura de memory.md

```
- Perfil: Dados pessoais e profissionais
- Preferências de trabalho: Como trabalhar juntos
- Projetos atuais: O que está em andamento
- Conhecimentos e expertise: Áreas de especialidade
- Feedback e lições aprendidas: Padrões que funcionam
- Referências úteis: Links e recursos
- Histórico de Chats: Conversas estruturadas com insights
```

## Atualizações

Novos chats são adicionados regularmente ao `memory.md` e commitados no repositório Git.
